# GPS Module

The GPS module is a high-performance BDS/GNSS positioning and navigation module built on the **ATGM336H-5N**. It supports several satellite navigation systems — all BeiDou-2 and BeiDou-3 satellites, GPS, GLONASS and QZSS — and can receive them simultaneously for combined positioning, navigation and timing. It offers high sensitivity, low power consumption and low cost, making it suitable for in-vehicle navigation, handheld positioning and wearables.

**1. Features**

- Supports all BeiDou-2 and BeiDou-3 satellites, IDs 1–63
- Single-system positioning on BDS / GPS / QZSS, or any combination of them
- A-GNSS support
- Cold-start acquisition sensitivity: -148 dBm
- Tracking sensitivity: -162 dBm
- Positioning accuracy: 2.5 m (CEP50)
- Time to first fix: 32 s
- Low power: 25 mA @ 3.3 V continuous
- Built-in antenna detection and antenna short-circuit protection
